# `dubna-site-demos` — публичное демо

Это заготовка отдельного **публичного** репозитория для GitHub Pages. Здесь только демо-макеты, без личных файлов, памяти, клиентских баз и паролей.

---

## Что внутри

```
public-demo/
  index.html          — страница со списком демо
  los-los/
    index.html        — демо для караоке-гастропаба
    los-los-logo.jpg  — логотип
  .nojekyll           — чтобы GitHub Pages не трогал файлы
```

---

## Как опубликовать

### 1. Создать репозиторий

На GitHub: **New repository** → имя `dubna-site-demos` → **Public** → без README (он уже есть).

### 2. Загрузить файлы

Из папки `D:\work\public-demo`:

```powershell
git init
git add .
git commit -m "Демо-макеты: сайт для караоке"
git branch -M main
git remote add origin https://github.com/<ваш-аккаунт>/dubna-site-demos.git
git push -u origin main
```

> Если GitHub просит пароль — используйте personal access token или GitHub CLI `gh auth login`. Пароль от аккаунта не подойдёт.

### 3. Включить Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, folder: `/ (root)` → Save.

Через 1–2 минуты ссылка:

```
https://<ваш-аккаунт>.github.io/dubna-site-demos/
```

Демо:

```
https://<ваш-аккаунт>.github.io/dubna-site-demos/los-los/
```

### 4. Свой домен (опционально)

Если нужен красивый адрес для демо — купите отдельный домен, например `demo-loslosos.ru`, и добавьте CNAME на `<ваш-аккаунт>.github.io`. Для клиентского продакшна всё равно нужен российский VPS, GitHub Pages — только витрина.

---

## Правила публикации

1. **Никогда** не публиковать из приватного проекта с памятью.
2. В репозитории не должно быть: телефонов клиентов, паролей, SSH-ключей, баз, скриншотов переписок, личных файлов.
3. Демо с брендом заведения публиковать **только после согласия** владельца. До согласия — нейтральная версия или показ с ноутбука.
4. На каждой странице — бейдж «Демо-макет · не официальный сайт».
5. Не выдавать демо за официальный сайт заведения.
6. Если владелец против — удалить демо из публичного репозитория в тот же день.
