## Как обновить

Из папки `D:\work\public-demo`:

```powershell
git add .
git commit -m "Демо: что изменил"
git push
```

GitHub Pages пересоберёт страницу за 1–2 минуты.

Проверить статус сборки:

```powershell
gh api repos/mirzemkv/dubna-site-demos/pages
```

## Правила публикации

1. В репозитории не должно быть: телефонов клиентов, паролей, SSH-ключей, баз, скриншотов переписок, личных файлов.
2. Демо с брендом заведения публикуется **только как явно помеченный демо-макет**. На каждой странице — бейдж «Демо-макет · не официальный сайт».
3. Не выдавать демо за официальный сайт заведения.
4. Если владелец против — удалить демо из публичного репозитория в тот же день.
5. Перед публикацией нового заведения проверять: нет телефонов клиентов, паролей, ключей, бд и личных файлов.
